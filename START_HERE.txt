QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════════

1. Install Dependencies:
   $ cd ZIE/backend && npm install
   $ cd ../frontend && npm install

2. Configure Environment:
   $ cd ZIE/backend
   $ cp .env.example .env
   # Edit .env with MongoDB URI and other settings

3. Start Services (3 Terminals):
   
   Terminal 1 - MongoDB:
   $ mongod (or brew services start mongodb-community)
   
   Terminal 2 - Backend:
   $ cd ZIE/backend && npm run dev
   # Should see: "Server running on port 5000"
   
   Terminal 3 - Frontend:
   $ cd ZIE/frontend && ng serve
   # Should see: "Application bundle generation complete"

4. Access Application:
   Open browser: http://localhost:4200

5. First User:
   Email: test@example.com
   Password: Test1234
   Role: Applicant (or Admin for testing)

API ENDPOINTS (15 Total)
═══════════════════════════════════════════════════════════════════════════════════

AUTHENTICATION (3):
  POST   /api/auth/register           - Register new user
  POST   /api/auth/login              - Login & get token
  GET    /api/auth/me                 - Get current user (protected)

APPLICATIONS (5):
  POST   /api/applications            - Submit application (protected)
  GET    /api/applications            - Get user's applications (protected)
  GET    /api/applications/:id        - Get details (protected)
  PUT    /api/applications/:id/status - Update status (admin)
  GET    /api/applications/admin/all  - All applications (admin)

SPONSORS (2):
  GET    /api/sponsors/:token         - Load appraisal form
  POST   /api/sponsors/:token/submit  - Submit appraisal
